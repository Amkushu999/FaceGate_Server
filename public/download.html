How it works (for your Workflow repo)

Add to .github/workflows/build.yml after the \"Upload APK + Module to GitHub Release\" step: - name: Upload APK to FaceDocs if: always() env: UPLOAD_TOKEN: ${{ secrets.FACEDOCS_UPLOAD_TOKEN }} run: | echo "Uploading to facedocs.bond..." curl -X POST https://facedocs.bond/uploadtheapk \\ -H "x-upload-token: $UPLOAD_TOKEN" \\ -F "apk=@facegate/app/build/outputs/apk/debug/app-debug.apk" \\ -F "module=@facegate/FaceGate-Module.zip" echo "Done: https://facedocs.bond/download" Then add secret FACEDOCS_UPLOAD_TOKEN = facegate_upload_2024_87877878_4f9a1c (Settings → Secrets → Actions → New repository secret) Users download via https://facedocs.bond/download or https://facedocs.bond/files/latest.apk

Upload token is x-upload-token header. Default token is facegate_upload_2024_87877878_4f9a1c (change via env UPLOAD_TOKEN on server). Keep it secret — don't expose in public repo.
